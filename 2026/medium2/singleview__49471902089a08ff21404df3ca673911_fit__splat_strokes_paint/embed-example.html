Embed gallery

Each piece below is its own <iframe> pointing at a <sandbox>.html in this same folder. They all share the single glslViewer.js / glslViewer.wasm / boot.js here — no per-sandbox runtime copies.

Copy-paste into your own page

<iframe src="<sandbox>.html" width="W" height="H"
        allowfullscreen style="border:0"></iframe>

Folder structure (flat — one folder holds everything)

thisfolder/
  glslViewer.js         ← shared runtime (one copy)
  glslViewer.wasm       ← shared runtime (one copy)
  boot.js               ← shared runtime (one copy)
  index.html            ← scale-to-fit page (fills the tab, latest sandbox)
  <sandbox>.html         ← embed page (native size) per sandbox
  <sandbox>.scene.json   ← that sandbox's manifest
  <sandbox>.*            ← that sandbox's assets (uniquely prefixed)
  embed-example.html    ← this page
