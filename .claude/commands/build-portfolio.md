## Step 5 — Sequence like an exhibition

Sequencing is not only aesthetic — it is meaning-making. Order the work for clarity and rhythm.

### Choose a structural approach:

**Option A — Grouping by project / period** (recommended for most contexts)
Group works into 2–3 coherent bodies. Each body establishes its internal logic before the next is introduced. Best when:
- Projects are meaningfully different from one another
- A project requires immersion to understand
- Clarity is more important than complexity
- Earlier-career submission where work is still consolidating

**Option B — Weaving between images and time periods**
Interleave works across years so viewers see connections and juxtapositions the chronology would hide. Best when:
- Work shares the same questions even across mediums and years
- The visual dialogue between works strengthens each
- The practice is highly cohesive and this can be demonstrated
- Patricio has enough work to sustain the complexity

*Caution:* weaving is structurally demanding. If the connections aren't immediately clear, the portfolio feels chaotic. Early-career artists should default to grouping. A **hybrid** is also valid: open with clean groupings to establish each body, then weave selectively toward the end to reveal integration.

**Simple test:** Does this work need to stand on its own to be understood? → Group. Does it become clearer alongside other specific works? → Weave.

### Sequencing principles:
- **Open strong.** The first work should represent the practice clearly and establish confidence. Decisions happen unconsciously in the first one to three images. Do not warm up slowly.
- **Create rhythm.** Alternate dense and spare compositions, dark and light, quiet and complex. If works blur together, viewers disengage. Avoid redundancy — if two pieces do the same thing, include only the stronger.
- **Close strong.** The final work should feel significant and suggest a direction for where the work is heading. It should inspire the decision you want the reviewer to make.

### Ordering methods within the structure:
- **Chronological** — useful only when demonstrating growth is the explicit goal
- **Inquiry + expansion** — Project A as foundation, Project B as its natural outgrowth
- **Thematic / conceptual** — show how an idea evolves across multiple projects
- **Material connections** — thread the practice through what each medium unlocks
- **Narrative arc** — hook early, deepen, pivot to create tension, resolve at the end
- **Anchors + satellites** — open with a central work that illuminates the core, then constellation supporting works around it

## Step 7 — Documentation quality check

Prompt Patricio to audit the documentation (photos, exports, scans) for each selected work:

**Must have:**
- Sharp, evenly lit, properly exposed images
- Color-accurate (matches the actual work)
- Undistorted (camera parallel to surface for 2D work; no keystoning)
- Clean crop, no studio clutter, no damaged walls, no unrelated objects

**Flag and fix:**
- Blurry images
- Heavy color casts (too yellow/warm or too blue/cool from gallery lighting)
- Tilted or skewed framing
- Dramatic shadows across the work surface

**Shot types to consider:**
- **Full view** — overall composition, complete assembly
- **Detail shot** — close-up showing brushwork, layering, edge conditions, surface texture, material joins; reveals artistic judgment invisible at a distance
- **Installation shot** — proves scale, demonstrates spatial intelligence, shows exhibition readiness; especially important for sculpture, installation, generative/screen work, and large-scale painting

Each shot type contributes different information. Together, full view + detail + installation produces a complete understanding of the work and the artist's intentions. When images are limited (JPEG upload cap), prioritize the shot type that answers the question a full view alone cannot.
