> _”When we forget ourselves, we are the universe.”_ Hakui

I was interested in what happens in the space between one person's mark and another's: whether two strangers, each drawing alone, could find themselves inside something they hadn't planned to share.

**Communitas** is a circular multi-touch table on which participants can make collaborative drawings. Drawings travel around the table inviting other participants to add to them, creating a collective and evolving artwork. The project was part of the Interactivos Telefónica fellowship, in Ciudad Autónoma de Buenos Aires, Argentina in 2010.
